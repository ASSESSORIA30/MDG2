# ModularDom Group Web

Proyecto React + Vite + TailwindCSS preparado para GitHub y Vercel.

## Subir a GitHub
Sube todo el contenido de esta carpeta. No subas `node_modules` ni `dist`.

## Vercel
Configuración recomendada:

- Framework Preset: Vite
- Install Command: npm install
- Build Command: npm run build
- Output Directory: dist

## Local
```bash
npm install
npm run dev
```
